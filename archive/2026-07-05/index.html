Manifesto

Why the World Needs a Protocol
for Trust Transfer

Trust is the foundation of all economic and social systems.

Today, trust is broken.

TodayWith ERC-8004-GT
Trust is a feelingTrust is a data structure
Trust is staticTrust evolves through challenge
Trust is opaqueTrust is auditable
Trust is centralizedTrust is decentralized
Trust is based on identityTrust is based on verifiable evidence

In the age of autonomous systems, the old model fails. AI agents make decisions that affect credit approvals, medical diagnoses, legal judgements, and scientific truth claims.

The question is not whether we trust the agent.

The question is: how do we verify, challenge, and audit the knowledge the agent uses?

ERC-8004-GT does not certify truth. It certifies the current verifiable epistemic state of an assertion.

The Agora Network exists to validate that any implementation of this standard is conformant, interoperable, and semantically stable — independently of any single organization, company, or protocol author.

ERC-20 standardized value transfer.
ERC-8004-GT standardizes trust transfer.

The Three Labs

What the Agora Network Does

Conformance Lab

Verifies that an implementation correctly supports the capabilities it claims Class A, B, or C against a canonical suite of test vectors.

Interoperability Lab

Runs cross-implementation tests: artifacts created by one system must be readable, verifiable, and challengeable by any other conformant system.

Semantic Stability Lab

Detects semantic drift: ensures the meaning of core entities Claim, Evidence, Artifact does not diverge across versions and implementations.
